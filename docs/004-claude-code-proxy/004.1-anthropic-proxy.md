# 004.1 - Anthropic-Compatible Proxy

**Phase 004: Claude Code Proxy** -- Sub-doc 1 of 4: `/v1/messages` SSE proxy endpoint.

> See also: [004.2 API Tokens](./004.2-api-tokens.md) | [004.3 Settings UI](./004.3-settings-ui.md) | [004.4 Credit Metering](./004.4-credit-metering.md)

## Overview

Anthropic-compatible `POST /v1/messages` endpoint that authenticates via `ac_` bearer tokens, resolves a provider pool, reserves credits, forwards to Claude API with the provider's decrypted key, streams SSE back, then meters usage and settles credits. Stateless per-request -- no session DO.

## Context & Background

Phase 2 delivered web chat via SessionAgent + WebSocket. Phase 4 adds a second consumer channel: Claude Code. Claude Code natively supports custom `ANTHROPIC_BASE_URL`, so the platform can intercept all requests by acting as a transparent proxy. Each request is independent (Claude Code manages conversation state).

## Goals

- Anthropic Messages API-compatible endpoint at `POST /v1/messages`
- Bearer token auth (`ac_...` prefix, SHA-256 lookup)
- Pool resolution from token's `default_pool_id` or `X-Pool-Id` header
- Credit reserve before forwarding, settle after stream ends
- SSE pass-through streaming to Claude Code
- Anthropic-format error responses for platform errors

## Non-Goals

- Persistent session state (Claude Code manages conversation)
- WebSocket transport (SSE only)
- Multi-provider routing (single pool per request)
- Rate limiting (Phase 5)

## 2. API Token Auth Middleware

File: `apps/data-service/src/hono/middleware/api-token-auth.ts`

```ts
import type { MiddlewareHandler } from "hono"
import { HTTPException } from "hono/http-exception"
import { getApiTokenByHash, updateApiTokenLastUsed } from "@repo/data-ops/queries/api-token"
import { getCreditBalance } from "@repo/data-ops/queries/credit"

interface ApiTokenContext {
  tokenUserId: string
  tokenId: string
  defaultPoolId: string | null
}

declare module "hono" {
  interface ContextVariableMap {
    apiToken: ApiTokenContext
  }
}

async function hashToken(raw: string): Promise<string> {
  const encoded = new TextEncoder().encode(raw)
  const digest = await crypto.subtle.digest("SHA-256", encoded)
  return Array.from(new Uint8Array(digest))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("")
}

export const apiTokenAuth = (): MiddlewareHandler => {
  return async (c, next) => {
    const authHeader = c.req.header("Authorization")
    if (!authHeader?.startsWith("Bearer ")) {
      throw new HTTPException(401, { message: "Authorization header required" })
    }

    const rawToken = authHeader.slice(7)
    if (!rawToken.startsWith("ac_")) {
      throw new HTTPException(401, { message: "Invalid token format" })
    }

    const hash = await hashToken(rawToken)
    const record = await getApiTokenByHash(hash)

    if (!record || !record.isActive) {
      throw new HTTPException(401, { message: "Invalid or revoked token" })
    }

    if (record.expiresAt && new Date(record.expiresAt) < new Date()) {
      throw new HTTPException(401, { message: "Token expired" })
    }

    c.set("apiToken", {
      tokenUserId: record.userId,
      tokenId: record.id,
      defaultPoolId: record.defaultPoolId,
    })

    // fire-and-forget last_used_at update
    c.executionCtx.waitUntil(updateApiTokenLastUsed(record.id))

    await next()
  }
}
```

## 3. Anthropic Proxy Handler

File: `apps/data-service/src/hono/handlers/anthropic-proxy-handlers.ts`

```ts
import { Hono } from "hono"
import { zValidator } from "@hono/zod-validator"
import { apiTokenAuth } from "../middleware/api-token-auth"
import { AnthropicMessagesRequestSchema } from "@repo/data-ops/zod-schema/anthropic-proxy"
import * as proxyService from "../services/anthropic-proxy-service"
import { anthropicError } from "../utils/anthropic-errors"

const proxy = new Hono<{ Bindings: Env }>()

proxy.use("/*", apiTokenAuth())

// POST /v1/messages
proxy.post(
  "/messages",
  zValidator("json", AnthropicMessagesRequestSchema, (result, c) => {
    if (!result.success) {
      return c.json(
        anthropicError("invalid_request_error", result.error.issues[0].message),
        400
      )
    }
  }),
  async (c) => {
    const body = c.req.valid("json")
    const apiToken = c.get("apiToken")
    const poolIdOverride = c.req.header("X-Pool-Id")

    const result = await proxyService.handleProxyRequest({
      body,
      userId: apiToken.tokenUserId,
      tokenId: apiToken.tokenId,
      defaultPoolId: apiToken.defaultPoolId,
      poolIdOverride: poolIdOverride ?? null,
      env: c.env,
    })

    if (!result.ok) {
      return c.json(
        anthropicError(result.errorType, result.errorMessage),
        result.statusCode
      )
    }

    // SSE pass-through
    return new Response(result.stream, {
      headers: {
        "Content-Type": "text/event-stream",
        "Cache-Control": "no-cache",
        Connection: "keep-alive",
      },
    })
  }
)

export default proxy
```

## 4. Anthropic Error Utility

```ts
import type { AnthropicErrorType, AnthropicErrorResponse } from "@repo/data-ops/zod-schema/anthropic-proxy"

export function anthropicError(
  type: AnthropicErrorType,
  message: string
): AnthropicErrorResponse {
  return { type: "error", error: { type, message } }
}

export function mapStatusToErrorType(status: number): AnthropicErrorType {
  switch (status) {
    case 400: return "invalid_request_error"
    case 401: return "authentication_error"
    case 403: return "permission_error"
    case 404: return "not_found_error"
    case 429: return "rate_limit_error"
    case 529: return "overloaded_error"
    default: return "api_error"
  }
}
```

### 5.2 Implementation

```ts
import { getPoolById } from "@repo/data-ops/queries/pool"
import { getProviderConfigById } from "@repo/data-ops/queries/provider"
import { getCreditBalance } from "@repo/data-ops/queries/credit"
import { reserveCreditsForRequest, settleCreditsForRequest } from "./proxy-credit-service"
import { decryptApiKey } from "./encryption"
import { calculateCreditsUsed } from "./token-meter"
import { mapStatusToErrorType } from "../utils/anthropic-errors"
import { ulid } from "ulid"

const CLAUDE_API_URL = "https://api.anthropic.com/v1/messages"

export async function handleProxyRequest(
  input: ProxyRequestInput
): Promise<ProxyResult> {
  // 1. Resolve pool
  const poolId = input.poolIdOverride ?? input.defaultPoolId
  if (!poolId) {
    return {
      ok: false,
      errorType: "invalid_request_error",
      errorMessage: "No pool configured. Set default_pool_id on your API token or pass X-Pool-Id header.",
      statusCode: 400,
    }
  }

  const pool = await getPoolById(poolId)
  if (!pool || pool.status !== "active") {
    return {
      ok: false,
      errorType: "not_found_error",
      errorMessage: "Pool not found or inactive",
      statusCode: 404,
    }
  }

  // 2. Validate model against pool allowlist
  if (!pool.allowedModels.includes(input.body.model)) {
    return {
      ok: false,
      errorType: "invalid_request_error",
      errorMessage: `Model "${input.body.model}" not allowed by this pool. Allowed: ${pool.allowedModels.join(", ")}`,
      statusCode: 400,
    }
  }

  // 3. Reserve credits (estimate from max_tokens)
  const estimatedCredits = calculateCreditsUsed(
    0,
    input.body.max_tokens,
    pool.creditsPerInputKToken,
    pool.creditsPerOutputKToken
  )

  const reserveResult = await reserveCreditsForRequest(input.userId, estimatedCredits)
  if (!reserveResult.ok) {
    return {
      ok: false,
      errorType: "invalid_request_error",
      errorMessage: `Insufficient credits (available: ${reserveResult.available}, estimated: ${estimatedCredits}). Top up at https://aigent.community/credits`,
      statusCode: 400,
    }
  }

  // 4. Get provider config + decrypt key
  const provider = await getProviderConfigById(pool.providerId)
  if (!provider || !provider.encryptedApiKey) {
    await reserveResult.rollback()
    return {
      ok: false,
      errorType: "api_error",
      errorMessage: "Provider configuration unavailable",
      statusCode: 502,
    }
  }

  const apiKey = await decryptApiKey(provider.encryptedApiKey, input.env.ENCRYPTION_KEY)

  // 5. Forward to Claude API
  const upstreamResponse = await fetch(CLAUDE_API_URL, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": apiKey,
      "anthropic-version": "2023-06-01",
    },
    body: JSON.stringify({
      ...input.body,
      stream: true,
    }),
  })

  if (!upstreamResponse.ok) {
    await reserveResult.rollback()
    const errorType = mapStatusToErrorType(upstreamResponse.status)
    let errorMessage = `Claude API error: ${upstreamResponse.status}`
    try {
      const errorBody = await upstreamResponse.json() as { error?: { message?: string } }
      if (errorBody?.error?.message) errorMessage = errorBody.error.message
    } catch { /* use default message */ }

    // Provider key invalid: auto-pause pool
    if (upstreamResponse.status === 401) {
      await pausePoolOnKeyInvalid(pool.id, provider.id)
    }

    return { ok: false, errorType, errorMessage, statusCode: upstreamResponse.status }
  }

  // 6. SSE pass-through with usage extraction
  const requestId = ulid()
  const { readable, writable } = new TransformStream()
  const writer = writable.getWriter()
  const reader = upstreamResponse.body!.getReader()
  const decoder = new TextDecoder()
  const encoder = new TextEncoder()

  let inputTokens = 0
  let outputTokens = 0
  let buffer = ""

  const pump = async () => {
    try {
      while (true) {
        const { done, value } = await reader.read()
        if (done) break

        const chunk = decoder.decode(value, { stream: true })
        buffer += chunk

        // Extract usage from SSE events while passing through
        const lines = buffer.split("\n")
        buffer = lines.pop() ?? ""

        for (const line of lines) {
          if (line.startsWith("data: ")) {
            const data = line.slice(6).trim()
            if (data && data !== "[DONE]") {
              try {
                const event = JSON.parse(data) as Record<string, unknown>
                if (event.type === "message_start") {
                  const msg = event.message as { usage?: { input_tokens: number } }
                  if (msg?.usage) inputTokens = msg.usage.input_tokens
                }
                if (event.type === "message_delta") {
                  const usage = event.usage as { output_tokens?: number } | undefined
                  if (usage?.output_tokens) outputTokens = usage.output_tokens
                }
              } catch { /* non-JSON line, pass through */ }
            }
          }
        }

        await writer.write(encoder.encode(chunk))
      }
      await writer.close()
    } catch (err) {
      await writer.abort(err instanceof Error ? err : new Error(String(err)))
    } finally {
      // Settle credits with actual usage
      await settleCreditsForRequest({
        userId: input.userId,
        providerId: provider.userId,
        poolId: pool.id,
        creditsReserved: estimatedCredits,
        inputTokens,
        outputTokens,
        creditsPerInputKToken: pool.creditsPerInputKToken,
        creditsPerOutputKToken: pool.creditsPerOutputKToken,
      })

      // Enqueue usage log
      await input.env.USAGE_LOG_QUEUE.send({
        id: requestId,
        tokenId: input.tokenId,
        poolId: pool.id,
        userId: input.userId,
        inputTokens,
        outputTokens,
        model: input.body.model,
        timestamp: Date.now(),
      })
    }
  }

  // Don't await -- pump runs in background
  input.env.ctx?.waitUntil?.(pump()) ?? pump()

  return { ok: true, stream: readable }
}
```

### 5.3 Pool Auto-Pause on Invalid Key

```ts
import { updatePool } from "@repo/data-ops/queries/pool"
import { updateProviderReputation } from "@repo/data-ops/queries/provider"

async function pausePoolOnKeyInvalid(
  poolId: string,
  providerId: string
): Promise<void> {
  await updatePool(poolId, { status: "paused" })
  await updateProviderReputation(providerId, -0.2)
}
```

## 7. Request Flow

```
Claude Code → POST /v1/messages (Bearer ac_...)
  ↓
apiTokenAuth middleware
  → SHA-256 hash token → lookup api_token table
  → set apiToken context (userId, tokenId, defaultPoolId)
  ↓
Zod validation (AnthropicMessagesRequestSchema)
  ↓
proxyService.handleProxyRequest()
  1. Resolve poolId (X-Pool-Id header || token's defaultPoolId)
  2. Validate model against pool.allowedModels
  3. Reserve credits (max_tokens × creditsPerOutputKToken)
  4. Decrypt provider API key
  5. Forward to api.anthropic.com/v1/messages (stream: true)
  6. Pipe SSE through TransformStream
     - Extract input_tokens from message_start
     - Extract output_tokens from message_delta
  7. On stream end: settle credits (actual vs reserved)
  8. Enqueue usage log to USAGE_LOG_QUEUE
  ↓
← SSE stream back to Claude Code
```
